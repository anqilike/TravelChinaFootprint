## 三、提交流程（按服务商的说明）

服务商的《服务指南》原文说明：**"按照我方的材料模版整理基础材料即可，比较简单，不用做的很全面，
因为大多数的材料都是我们帮您完善和整理的，前期不需要客户提前打印盖章材料。"**

所以流程很短：

1. 在华为云商店选择规格并付款（建议 **10-15 个工作日 / ¥480** 那档）；
2. 把本材料包里的三份文档 + 说明书 PDF + 身份证，一起发给服务商；
3. 服务商整理材料，如有问题会反馈补充；
4. 服务商提交，等待下证；
5. 拿到 PDF 格式的《电子版权认证证书》后，在 AGC 上传：
   - 「版本信息 → 版权信息 → **电子版权证书**」栏：上传 PDF（≤5MB）
   - 「版本信息 → 版权信息 → **应用版权证书或代理证书**」栏：上传证书的图片版（JPG/PNG，≤15MB/张）

## 四、必须核对的三件事

### 1. 名称必须完全一致

证书上的软件名称必须是「**走遍中国**」，与下列四处保持一致：
AGC 上架名称、包内 `app_name`、APP 备案名称、软著登记名称。
写错一个字都要重办。

### 2. 首次发表日期填「未发表」

应用尚未上架，如实选择"未发表"，不要编造日期——否则会与后续备案信息冲突。

### 3. 一个证书对应一个应用

版权证书与单一应用绑定，不能一个证书给多个应用使用（小米/华为的规则均如此）。
