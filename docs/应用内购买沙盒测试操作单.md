## 一、先建商品（沙盒测试的前提）

路径：AGC → 我的项目 → 走遍中国 → **盈利 → 应用内购买服务 → 商品管理 → 添加商品**

| 字段 | 填写内容 |
|---|---|
| 类型 | **非消耗型**（创建后不可改） |
| 商品 ID | **travelchina_lifetime**（必须与代码 `IapService.PRODUCT_LIFETIME` 一致） |
| 语言 | 简体中文 |
| 商品名称 | 走遍中国 · 终身会员 |
| 商品简介 | 一次买断，永久解锁全部 370 座城市 |
| 商品销售范围 | 中国大陆 |
| 商品价格（含税） | **¥6.00** |

### 审核信息（不填会被驳回）

| 字段 | 填写内容 |
|---|---|
| 应用内截图 | `D:\China\_tools\k5.jpeg`（购买面板截图，1280×2832，符合 ≥640×920） |
| 应用内路径 | 地图 → 点亮任意城市（第 6 座）→ 弹出购买面板；或「我的 → 开通终身会员」 |
| 备注信息 | 见下方模板 |

备注模板（直接复制）：

```
本应用为"记录去过哪些城市"的本地工具，无登录门槛，安装后即可使用。
免费体验额度为 5 座城市；在【地图】页连续点亮 6 座城市，第 6 座会弹出本购买面板；
也可以从【我的】页面 →【开通终身会员】直接进入购买面板。
商品为非消耗型（终身买断），购买后立即解锁全部城市，价格与商品信息由 IAP Kit 返回。
```

> **保存后先不要提交审核**。商品处于"草稿/待提交"状态时最适合做沙盒测试；
> 等沙盒跑通再提交商品审核。

## 二、添加沙盒测试账号

路径：AGC → **用户与访问 → 沙盒测试 → 测试账号 → 新增**

- 必须是**真实可用的华为账号**（手机号注册的即可）
- 填昵称、华为账号、验证信息后提交
- **配置 5~10 分钟才生效**，别急着马上测

> 建议直接用你手机上登录的那个华为账号，省得来回切号。

## 三、真机沙盒测试（8 步）

正式开测前确认三件事：

| 条件 | 你的状态 |
|---|---|
| App 是 debug 签名 | ✅ 当前工程用 `debugKey` + `travelchina_debug.p7b` |
| 设备已登录沙盒测试账号 | 待确认 |
| AGC 已添加该账号 | 待完成 |

测试步骤：

1. 用数据线连手机，运行：
   `powershell -ExecutionPolicy Bypass -File D:\China\_tools\dev.ps1 -SkipBuild -WaitSeconds 14`
2. 打开 App → 地图页，确认当前点亮城市数（若已超过 5 座，会直接进入付费状态）
3. 点击一座**未点亮**的城市 → 弹出城市卡片 → 点「开通会员并点亮」
4. 弹出购买面板 → 点「¥6.00 开通终身会员」
5. 应拉起**华为收银台**，并在页面上看到**沙盒环境提示**
   > ⚠️ 如果没看到沙盒提示，说明沙盒没生效，继续付款会**真实扣费**，请立即取消！
6. 完成支付（沙盒不扣钱）→ 返回 App
7. 预期结果：
   - 「我的」页显示"终身会员 · 已开通（沙盒测试）"
   - 地图顶部"免费名额已用完"入口消失
   - 刚才那座城市被自动点亮
8. 验证恢复购买：AGC 沙盒测试页「清除购买历史记录」后，点「已购买过？恢复购买」
   （沙盒下确认发货后订单不会再被 queryPurchases 返回，所以要先清历史）

## 四、沙盒测试通过后

| 步骤 | 说明 |
|---|---|
| 1 | 把商品**提交审核**（AGC 商品管理 → 提交审核） |
| 2 | 到 AGC「证书、APP ID 和 Profile」**重新申请发布 Profile**（开通 IAP 后必须重签） |
| 3 | 申请发布证书，替换工程里的 debug 签名 |
| 4 | 导出正式包的公钥 / 签名 MD5，用于 APP 备案 |
| 5 | 备案通过后，提审上架 |

> 顺序记忆：**沙盒通 → 商品提审 → 发布签名 → 备案 → 提审**

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点购买直接报"应用内购买服务尚未生效" | 服务未激活 / 商品没建 / 签名不是 debug | 逐项检查 |
| 收银台没有沙盒提示 | 测试账号没生效（5~10 分钟）或设备登录的不是该账号 | 等待后重试，确认账号 |
| 商品查不到（1001860003） | 商品 ID 写错 / 商品未生效 / 销售范围不含账号服务地 | 核对 `travelchina_lifetime`、中国大陆 |
| 购买成功但没解锁 | 客户端 finishPurchase 之前异常 | 重新进入 App 会自动补发货 |
| 恢复购买查不到订单 | 沙盒下订单确认发货后不再返回 | AGC 清除购买历史记录后重测 |
