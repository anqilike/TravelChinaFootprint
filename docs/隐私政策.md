## 导语

走遍中国是一款"记录你去过哪些城市"的本地工具应用。我们坚持最小必要原则：不注册也能使用全部核心功能，位置与账号都由你主动触发。

## 一、我们收集哪些信息

1. **位置信息（可选）**：只有当你主动点击"定位到我的位置"时，应用才会通过系统定位能力获取一次当前位置，用于识别你当前所在的地级市，方便一键点亮。
2. **足迹数据（仅本机）**：你点亮的城市、日期、标签、备注、同行人，全部保存在本机应用沙箱内。
3. **华为账号信息（可选）**：只有当你主动点击"登录华为账号"时，应用才会保存华为账号返回的 openID / unionID，用于在云同步时区分数据归属。

## 二、我们不收集什么

- 不读取通讯录、短信、相册、剪贴板；
- 不获取设备唯一标识（IMEI / OAID 等），不做用户画像；
- 不接入任何第三方广告或统计 SDK，不向第三方出售、共享你的个人信息；
- 位置信息不上传、不留存轨迹。

## 三、信息如何存储与使用

- 默认全部数据仅保存在本机（应用沙箱数据库 `footprint.db`），卸载应用即删除。
- 只有当你主动登录华为账号并点击"立即同步"后，足迹数据才会通过华为云同步到你自己账号下；开发者无法读取你在云端的个人数据。
- 位置信息仅用于"当前城市识别"，使用后即丢弃，不写日志、不上传。

## 四、使用的第三方服务

- **华为 Map Kit**（地图底图、坐标转换、审图号展示）——由华为提供地图服务；
- **华为 Account Kit**（华为账号登录）；
- **华为云（Cloud Foundation Kit）**（仅在开启云同步时使用）。

上述服务均按华为官方的隐私声明处理数据。

## 五、你的权利

- **查看与导出**：我的 → "导出我的足迹"，可导出 JSON 文件；
- **更正与删除**：在我的 → 清单中删除对应记录，或使用 我的 → "清除本机足迹数据"；
- **撤回同意**：卸载应用即撤回，本机数据同时被删除。

## 六、未成年人保护

本应用不面向 14 周岁以下儿童单独提供服务，也不会主动收集儿童个人信息。如监护人发现相关情况，可通过下方联系方式要求删除。

## 七、政策更新

隐私政策如有实质性变更，应用会在启动时重新征求你的同意，并更新版本号。
