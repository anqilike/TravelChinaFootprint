## 五、软件简介（可直接粘贴）

### 短版（约 60 字，用于列表/摘要栏）

```
走遍中国是一款城市足迹记录工具：在全国地图上点选城市即可记录到访，
已到访城市点亮为金色，未到访保持暗色，一眼看出足迹覆盖范围。
```

### 长版（约 300 字，用于"软件简介/开发目的"栏）

```
走遍中国是一款运行于 HarmonyOS 系统的工具类应用软件，用于记录用户到访过的城市，
并以地图点亮的可视化方式呈现在全国范围内的足迹覆盖情况。

软件内置全国 370 个市州级行政区的地理点位数据，用户在地图上点选城市即可完成记录。
已经到访的城市以金色圆点与金色名称显示，未到访的城市保持暗色，从而让用户一眼看出
自己走过了哪些地方、还有哪些地方没有去过。

除地图点亮之外，软件还提供足迹清单（按省级行政区聚合浏览、搜索与批量点亮）、
统计与成就（覆盖率、到访最多的城市、9 枚成就徽章）、数据导出（JSON 格式备份）、
华为账号登录与云端同步（可选）等辅助功能。

软件坚持隐私最小必要原则：足迹数据默认只保存在本机，位置信息仅在用户主动点击时
获取一次，不上传、不留轨迹；不接入第三方广告与统计 SDK，不采集设备唯一标识。
```

## 六、主要功能（可直接粘贴）

```
1. 地图点亮：在全国地图上点选城市完成到访记录，支持记录日期、标签（出差/旅行/探亲/
   路过/居住）与备注；
2. 分级标注：随地图缩放自动切换标注层级，全国视野显示省名、放大显示省会、
   再放大显示全部地级市名称；
3. 足迹清单：按省级行政区聚合展示全部 370 个城市，支持搜索、状态筛选与批量点亮；
4. 统计与成就：展示全国覆盖率、已点亮数量、覆盖省级行政区数量、到访最多的城市，
   以及 9 枚成就徽章（首站、十城、五十城、百城、两百城、半壁江山、华东全境、
   四大直辖、全国制霸）；
5. 数据导出：将已点亮城市清单导出为 JSON 文件，便于备份与换机；
6. 账号与云同步：支持华为账号一键登录，可将足迹同步至云端（可选功能）；
7. 个性设置：大字号模式、色盲友好模式、8 种点亮配色、10 种徽章点亮动画；
8. 隐私保护：首次启动展示隐私政策并征得同意，应用内可随时查阅全文。
```

## 七、技术特点（可直接粘贴）

```
1. 采用 HarmonyOS 官方推荐的 ArkTS 语言与 ArkUI 声明式开发范式，目标 API 版本 26
   （HarmonyOS 7），同时向下兼容 HarmonyOS 5.0.0 及以上版本；
2. 使用华为 Map Kit 提供地图底图与坐标转换服务，地图左下角完整展示审图号
   （GS (2024) 1955号）；软件不绘制行政区域边界几何，仅叠加城市点位与名称标注；
3. 采用 relationalStore 关系型数据库在应用沙箱内本地存储数据，并以城市维度建立索引；
4. 实现三级地名标注自动切换与标签碰撞避让，保证不同缩放级别下的地图可读性；
5. 已点亮点位采用基于行政区划代码派生的差异化频率呼吸式闪烁效果，视觉层次清晰；
6. 适配 HarmonyOS 7 沉浸光感材质，在较旧系统上自动降级，保证多版本兼容性。
```
