路径：**华为开发者联盟 → 管理中心 → 开发者中心 → 商户服务**

1. **经营场景**：勾选 **「其他」**（本应用尚未上架，官方明确要求选这项，不要选「APP」）

3. **补充信息**（建议原文照抄）：

```

1) 应用首页（地图功能，可见应用名称与功能形态）；
2) 「我的 → 关于」页：展示应用名称、开发者（吕志方 / 个人开发者）、联系邮箱；
3) 应用内隐私政策第八节：展示"本应用《走遍中国》由 吕志方（个人开发者）开发并提供"。

开发者信息与公网隐私政策（https://anqilike.github.io/TravelChinaFootprint/privacy-policy.html）完全一致。
```

4. **经营类目**保持现状即可（网络媒体/计算机服务/游戏 → 软件/建站/技术开发）
5. 检查银行信息（当前填的是：中国银行 四川 成都 成都府青路支行，开户行号 104651065325）
