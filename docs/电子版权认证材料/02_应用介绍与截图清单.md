## 一、应用介绍

### 商店用一句话简介

```
点亮你去过的每一座城市
```

### 应用介绍（约 300 字，可直接粘贴到"应用介绍"栏）

```
走遍中国是一款把"我去过哪里"变成一张可点亮地图的工具类应用。

打开应用，你会看到一张完整的中国地图：全国 370 个市州级行政区各自有一个点位，
去过的城市点亮成金色，没去过的保持暗色，一眼就能看出你的足迹覆盖了哪些地方。

主要功能：
1. 点亮足迹：点选地图上的城市即可记录到访，支持记录日期、标签（出差/旅行/探亲/
   路过/居住）与备注；
2. 分级标注：全国视野显示省份名，放大后依次显示省会、地级市名称；
3. 足迹清单：按省份分组浏览全部城市，支持搜索、批量点亮、按已点亮/未点亮筛选；
4. 统计与成就：覆盖率、到访最多的城市、9 枚成就徽章；
5. 数据导出：一键导出 JSON，换机或备份都方便；
6. 隐私优先：足迹数据默认只存本机，位置信息仅在用户主动点击时获取一次，
   不上传、不留轨迹。

应用适配 HarmonyOS 6 与 HarmonyOS 7。
```

### 版本说明

```
首个正式版本 V1.0：全国 370 个市州级行政区点位；地图点选点亮；三级地名标注；
足迹清单与统计成就；数据导出；华为账号登录与云同步（可选）；
适配 HarmonyOS 7 沉浸光感材质，HarmonyOS 6 自动降级。
```
