## 一、华为到底认哪两种？（官方口径）

来源：华为开发者联盟官方文章《在应用市场上架APP所需的版权证书获取方法（汇总）》
<https://developer.huawei.com/consumer/cn/blog/topic/03156462034230019>

> 华为应用市场认可的版权证明有两种：一种是中国版权保护中心发的"**软件著作权**"，
> 另一种是**易版权**发的"**电子版权证书**"。

另外一个官方口径（《应用资质审核要求》2026-09-02 更新）：

> APP软件著作权证书为"非必选资质"，但**建议**您申请《计算机软件著作权登记证书》、
> 《APP电子版权证书》或《软件著作权认证证书》以保护您的知识产权。

⚠️ **两份官方文档说法不一致**（一份说"手机应用必选"，一份说"非必选"）。
实操建议：**按必选准备**——AGC 提交页那个字段大概率带红星，缺了会被驳回，
而补办的周期是 3 天~3 个月，卡在这里不划算。

### 应用介绍（约 300 字，申请表"软件简介"栏可用）

```
走遍中国是一款把"我去过哪里"变成一张可点亮地图的工具类应用。

打开应用，你会看到一张完整的中国地图：全国 370 个市州级行政区各自有一个点位，
去过的城市点亮成金色，没去过的保持暗色，一眼就能看出足迹覆盖了哪些地方。

主要功能：
1. 点亮足迹：点选地图上的城市即可记录到访，支持记录日期、标签（出差/旅行/探亲/路过/居住）与备注；
2. 分级标注：全国视野显示省份名，放大后依次显示省会、地级市名称；
3. 足迹清单：按省份分组浏览全部城市，支持搜索、批量点亮、按已点亮/未点亮筛选；
4. 统计与成就：覆盖率、到访最多的城市、9 枚成就徽章；
5. 数据导出：一键导出 JSON，换机或备份都方便；
6. 隐私优先：足迹数据默认只存本机，位置信息仅在用户主动点击时获取一次，不上传、不留轨迹。

应用适配 HarmonyOS 6 与 HarmonyOS 7。
```

## 五、软件说明书（可作为"操作说明书"材料提交）

### 5.1 软件概述

**软件名称**：走遍中国

### 5.2 主要功能模块

| 模块 | 功能说明 |
|---|---|
| 地图页 | 展示全国 370 个市州级行政区点位；已点亮城市以金色圆点与金色名称呈现，并做差异化频率的呼吸式闪烁；支持全国视野 / 省会 / 地级市三级标注自动切换；支持缩放、定位、只看已点亮等操作 |
| 城市卡片 | 点击地图上的城市弹出半模态卡片，可查看/编辑到访日期、标签、备注，并完成点亮或取消点亮 |
| 足迹清单 | 按省级行政区聚合展示全部城市，支持关键词搜索、已点亮/未点亮筛选、批量点亮 |
| 统计与成就 | 覆盖率环形图、已点亮数量、覆盖省级行政区数量、到访最多的城市，以及 9 枚成就徽章的解锁进度 |
| 我的 / 设置 | 华为账号登录（可选）、数据导出（JSON）、清除本机数据、大字号与色盲友好模式、点亮配色与徽章动画选择、开发者信息与隐私政策 |
| 隐私合规 | 首次启动展示隐私政策并征得同意；应用内可随时查看隐私政策全文 |

### 5.3 技术特点

1. 采用 HarmonyOS 官方 Map Kit 提供地图底图与坐标转换，地图审图号由地图服务方标注并展示；
2. 采用关系型数据库（relationalStore）在应用沙箱内本地存储全部足迹数据，卸载即删除；
3. 适配鸿蒙 7 沉浸光感材质（底部悬浮页签栏使用系统材质），鸿蒙 6 自动降级为毛玻璃；
4. 不接入任何第三方广告或统计 SDK，不采集设备唯一标识。

## 六、办理流程（照着走）

1. 打开华为云商店该商品页，选择规格（建议 **10-15 个工作日 / ¥480**）
2. 立即购买 → 用你的华为账号登录 → 支付
3. 按服务商要求提交材料：**身份证 + 本文件第三、四、五节的文字与图片**
4. 等待下证（PDF 格式电子版权证书）
5. 拿到证书后：AGC → APP与元服务 → 走遍中国 → **版本信息 → 版权信息**：
   - "**电子版权证书**"栏上传 PDF（≤5MB）
   - "**应用版权证书或代理证书**"栏上传证书的图片版（JPG/PNG，≤15MB/张）

## 七、常见坑

1. **名称不一致**：证书上的名字必须是「走遍中国」，写"华夏足迹""旅游足迹"之类都会被退回重办；
2. **首次发表日期乱填**：应用未上架就选"未发表"，不要编日期（与后续备案信息冲突会麻烦）；
3. **只办电子版权、忘了备案**：电子版权认证不替代 APP 备案，两者是**各自独立**的必办项；
4. **证书有效期**：电子版权证书本身长期有效，但应用改名/主体变更后需要重新办理。
