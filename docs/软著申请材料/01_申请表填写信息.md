## 三、主要功能（申请表"软件主要功能"栏，可直接粘贴）

```
本软件是一款运行于 HarmonyOS 系统的城市足迹记录工具。软件内置全国 370 个市州级行政区
地理点位数据，用户在地图上点选城市即可完成到访记录，已到访城市以金色圆点与金色名称显示，
未到访城市保持暗色，从而直观呈现足迹覆盖范围。

主要功能包括：
1. 地图点亮：在全国地图上点选城市完成记录，支持记录到访日期、标签与备注；
2. 分级标注：随地图缩放自动切换标注层级，全国视野显示省名、放大显示省会、再放大显示全部地级市；
3. 足迹清单：按省级行政区聚合展示全部城市，支持搜索、状态筛选与批量点亮；
4. 统计与成就：展示覆盖率、已点亮数量、覆盖省级行政区数量、到访最多的城市，以及 9 枚成就徽章；
5. 数据导出：将已点亮城市清单导出为 JSON 文件，便于备份与换机；
6. 账号与云同步：支持华为账号一键登录，可将足迹同步至云端（可选）；
7. 个性设置：大字号模式、色盲友好模式、点亮配色与徽章动画选择；
8. 隐私保护：首次启动展示隐私政策并征得同意，足迹数据默认仅保存在本机。
```

## 四、技术特点（申请表"技术特点"栏，可直接粘贴）

```
1. 采用 HarmonyOS 官方 ArkTS 语言与 ArkUI 声明式开发范式，目标 API 版本 26（HarmonyOS 7），
   向下兼容 HarmonyOS 5.0.0 及以上；
2. 使用华为 Map Kit 提供地图底图与坐标转换，地图审图号由地图服务方标注并展示；
3. 采用 relationalStore 关系型数据库在应用沙箱内本地存储数据，并以城市维度建立索引；
4. 实现三级地名标注自动切换与标签碰撞避让，保证不同缩放下地图可读性；
5. 已点亮点位采用基于行政区划代码派生的差异化频率呼吸式闪烁效果；
6. 适配 HarmonyOS 7 沉浸光感材质，旧版本系统自动降级，保证多版本兼容。
```
