## 二、现在就能做（不必等软著）

### ① 发布签名（最高优先级）

为什么现在做：**上架和 APP 备案都以它为前提**。备案要填签名包的公钥与 MD5，
没有发布签名就没法备案；没有备案就没法上架。

步骤：

1. AGC → 证书、APP ID 和 Profile → 申请**发布证书**（.cer）
2. 注册发布 Profile（.p7b）
3. 下载后替换工程里的调试签名配置（当前是 `debugKey` + `travelchina_debug.p7b`）
4. 打出正式包，导出公钥 / 签名 MD5，供备案使用

### ② APP 备案

拿到发布签名后即可提交。需要：主体身份证、手机号、邮箱、应用名称、
包名 `com.TravelChina.footprint`、图标、**签名公钥与 MD5**、无服务器说明。

### ③ 应用内购买服务（2026-10-18 沙盒已通过）

已完成：

- 调试 Profile v2 已包含 Map Kit + IAP 能力，重新签名并安装到 Mate 80；
- 真机完成 `queryProducts → createPurchase → 权益发放 → finishPurchase`；
- 收银台明确显示沙盒环境，订单尾号 `892254`，购买不产生扣费；
- App 重启后会员状态仍然保留；
- AGC 商品 `travelchina_lifetime` 的中国区价格已从 ¥1.00 修正为 **¥6.00**。

商品当前状态为「待提交」。AGC 提示：**首个数字商品必须随新的应用版本提交**，
因此不要单独提交商品审核，下一步应准备发布签名与新版本。

### ④ 决定付费墙策略

应用目前是"免费体验 5 座，第 6 座起需要 ¥6 终身会员"。
如果 IAP 尚未生效就提交上架，用户点到第 6 座会看到"应用内购买服务尚未生效"，
审核可能判为功能不可用。两个选择：

- **等 IAP 全流程跑通再提审**（推荐）；
- 或在提审版本中临时关闭付费门槛，IAP 生效后再发 1.0.1 加回。
