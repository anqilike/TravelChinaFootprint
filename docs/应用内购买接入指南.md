## 一、开通前的两个前置动作（必须按顺序）

### 1. 开通商户服务

**位置**：AGC → 右上角账号 → **商户服务**

商户服务是"分发付费内容"的前提，需要配置**银行卡账户、币种**，用于接收华为的分成收益。
官方说明：<https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-enable-merchant-service>

> 这一步涉及银行账户信息，只能你本人填写。
> 注意：**个人开发者**同样可以开通，结算主体与实名信息绑定。

### 2. 开启并激活应用内购买服务

**位置**：AGC → 我的项目 → 走遍中国 → **盈利 → 应用内购买服务（HarmonyOS NEXT）** → 立即开通

当前状态：**未开通**（页面显示"立即开通"按钮）。

官方说明：<https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-enable-in-app-purchases>

⚠️ 官方明确要求：**开启和激活"应用内购买服务"之后，需要重新申请发布 Profile 文件并手动签名**，
否则打出来的包里没有该能力，正式环境调 `createPurchase` 会返回 `1001860002 应用未授权`。

## 二、创建商品（最关键的一步）

**位置**：AGC → **APP 与元服务** → 走遍中国 → **运营 → 产品运营 → 商品管理 → 商品列表 → 添加商品**

> 如果提示"请先设置应用分发国家/地区"，先在应用信息里把分发地区设为**中国大陆**
> （当前 HarmonyOS 数字商品只支持中国大陆销售）。

按下表填写（与代码强相关，**商品 ID 错了就查不到商品**）：

| 字段 | 填写内容 | 说明 |
|---|---|---|
| 类型 | **非消耗型** | 一次买断、永久拥有。⚠️ 创建后**类型不可修改** |
| 商品 ID | `travelchina_lifetime` | 必须与 `IapService.PRODUCT_LIFETIME` 完全一致；保存后不可修改、删除后也不可复用 |
| 语言 | 简体中文 | 只配置一种语言即可 |
| 商品名称 | `走遍中国 · 终身会员` | ≤55 字符 |
| 商品简介 | `一次买断，永久解锁全部 370 座城市` | ≤100 字符 |
| 商品销售范围 | 中国大陆 | 至少选 1 个国家/地区 |
| 商品价格（含税） | **¥6.00** | 手动编辑或"汇率换算基准价格"配置；界面价格取自这里 |

### 审核信息（容易被忽略，但不填会被驳回）

| 字段 | 建议填写 |
|---|---|
| 应用内截图 | JPG/PNG，≥640×920，≤5MB。截图内容：购买面板（`¥6.00 开通终身会员`） |
| 应用内路径 | `地图 → 点亮任意城市（第 6 座）→ 弹出购买面板`；或 `我的 → 开通终身会员` |
| 备注信息 | 见下方模板 |

**备注模板**（可直接粘贴）：

```
本应用为"记录去过哪些城市"的本地工具，无登录门槛，安装后即可使用。
免费体验额度为 5 座城市；在【地图】页连续点亮 6 座城市，第 6 座会弹出本购买面板；
也可以从【我的】页面 →【开通终身会员】直接进入购买面板。
商品为非消耗型（终身买断），购买后立即解锁全部城市，价格与商品信息由 IAP Kit 返回。
```

## 三、沙盒测试（不花真钱，但流程完全一致）

官方说明：<https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-sandbox>

三个条件缺一不可：

1. **添加测试账号**：AGC → **用户与访问 → 沙盒测试 → 测试账号 → 新增**（必须是真实华为账号，配置 5~10 分钟生效）；
2. **应用是 debug 签名**：当前命令行打的就是 debug 包，满足；
3. **设备上登录的是该测试账号**。

自检接口：`iap.isSandboxActivated()`（代码里已有封装 `IapService.isSandbox()`）。

沙盒环境的几个特点：

- 订单**不真实扣费**，但需要绑定过付款方式；
- 订单里 `environment` 字段为 `SANDBOX`，代码会把会员标记成"沙盒测试"，在「我的」页面里显示出来；
- 非消耗型商品**确认发货后，该订单不会再被 `queryPurchases` 返回**，
  所以沙盒下验证"恢复购买"前，先在 AGC 里**清除购买历史记录**；
- 测试充值/退款：AGC → 用户与访问 → 沙盒测试 → 测试账号 → **清除购买历史记录**。

### 验证顺序（建议照做）

1. 手机上点亮 5 座城市 → 第 6 座应弹出购买面板（当前代码：老用户会被记为"已用 5 座"）；
2. 点「¥6.00 开通终身会员」→ 应拉起收银台并显示**沙盒**提示；
3. 支付成功后返回 App → 顶部"免费名额已用完"入口消失，「我的」页面显示"终身会员 · 已开通（沙盒测试）"；
4. 卸载重装 → 打开 App 会自动静默恢复会员（`restoreOnLaunch`）；
5. 在「我的」→「已购买过？恢复购买」手动再验证一次。

## 四、代码与 AGC 配置的对应关系

| AGC 配置 | 代码位置 | 说明 |
|---|---|---|
| 商品 ID | `IapService.PRODUCT_LIFETIME` | 两处必须一致 |
| 商品类型 | `iap.ProductType.NONCONSUMABLE` | 非消耗型 |
| 商品价格 | `IapService.queryProduct()` → `product.localPrice` | 界面只展示这个值，不写死 |
| 商品名称 | 购买面板标题旁的商品名 | 取 `product.name` |
| 免费额度 | `MembershipService.FREE_QUOTA = 5` | 改这里即可调整体验额度 |

## 五、官方硬性规范（违反可能影响上架）

来源：<https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-access-specifications>

1. **商品购买页不得展示支付方式信息**：不能出现"华为支付 / 鸿蒙支付 / 应用内支付"等名称或 logo，
   只保留一个购买按钮 —— 本应用的购买面板已按此设计（面板里没有任何支付方式字样）；
2. **数字商品必须走 IAP Kit**，不得接入支付宝 / 微信等第三方支付；
3. 点击购买后直接拉起系统收银台，中间可以有加载动效 —— 按钮在请求期间显示"正在拉起收银台…"；
4. 商品价格必须使用 IAP Kit 返回的本地化价格。

## 七、收费、退款与售后

- **分成与结算**：商品价格是"用户支付价（含税）"，华为按当地税率扣税后与开发者分成，
  实际到账以 AGC 对账单为准；结算走第一步开通的**商户服务**里的银行卡账户。
- **价格维护**：AGC 不会跟随汇率自动刷新历史价格，需要定期手动刷新（我方是人民币单一定价，影响很小）。
- **退款**：用户可在"华为账号 → 付款与账单 → 购买记录"发起退款申请；
  IAP 提供 `iap.createRefundRequest()`（非游戏应用）可以在应用内发起退款流程，本版本未接入，
  如需在应用内提供"申请退款"入口，可在「我的」页面补充（约 20 行代码）。
- **退款后的权益**：本应用是单机应用，退款事件通过"服务端关键事件通知"下发；
  未接通知前不会自动回收权益，可后续按需补充。
