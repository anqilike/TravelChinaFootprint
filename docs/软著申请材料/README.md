## 二、三分钟上手：现在就能提交

1. 打开 <https://register.ccopyright.com.cn/registration.html#/registerSoft>，注册并实名认证；
2. 按 `01_申请表填写信息.md` 逐项填写；
3. 上传两个 PDF：源程序 + 软件说明书；
4. 上传身份证正反面照片；
5. 提交，等待受理（受理后 60 日内出证）。

详细步骤见 `02_申报流程指南.md`。

## 四、几个关键提醒

1. **名称不能改**：软著证书上的名称必须与 AGC 上架名称、包内 `app_name`、APP 备案名称
   四处完全一致。若日后确实需要改名，需办理《软件著作权登记事项变更或补充登记》。
2. **功能后续迭代不影响本次登记**：登记的是「软件作品」而非某个版本，
   后续加功能、改 UI、升版本号都不需要重新登记（详见
   [../版权认证材料/README.md](../版权认证材料/README.md) 第八节）。
3. **两个 PDF 都可直接使用**：源程序 60 页、说明书 25 页（不足 60 页按实际提交）。
4. **建议今天提交**：软著审查周期为受理后 60 日内，越早提交越早拿证；
   期间可并行推进 APP 备案与发布签名。
