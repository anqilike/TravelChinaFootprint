# 走遍中国 · 应用图标需求说明

> 用途：AppGallery 上架图标 / 应用内分层图标 / 启动图标 / 网页与 README 配图
> 现状：已有一版程序化生成的定稿（见 `docs/store-assets/`），本文档既可作为"改版依据"，
> 也可以直接丢给 AI 绘图工具或设计师出更多方案。

---

## 一、这个图标要表达什么

**一句话**：一片还没点亮的暗点里，有一颗被点亮的金点。

它是应用核心体验的压缩——打开地图看到全国 370 个点位，**去过的城市点亮成金色**。
图标不解释功能、不放文字，只传递那种"某个坐标被我点亮了"的瞬间。

---

## 二、硬约束（不满足就废稿）

| # | 约束 | 原因 |
|---|---|---|
| 1 | **不得出现中国地图轮廓、国界线、省界** | 本应用刻意回避"地图编制资质"问题（《设计前指导书》附录 G）；图标同理，只用抽象几何 |
| 2 | 图标内**不放任何文字、字母、数字** | 多语言与缩小时的清晰度 |
| 3 | 不使用第三方商标、水印、素材库剪影 | 上架审核 |
| 4 | 边缘必须干净：**无白边、无锯齿、无半透明脏边** | 商店会在浅色/深色背景上同时展示 |
| 5 | **缩到 72×72 仍能一眼认出主体** | 应用列表、搜索结果里就是这个尺寸 |
| 6 | 圆角约为边长的 **22%**（鸿蒙/应用市场的默认形状） | 与系统图标观感一致 |
| 7 | 主体内容控制在画面中央 **约 62% 的安全区**内 | 鸿蒙分层图标会被系统按圆形/圆角方形/水滴形裁切，太靠边会被切掉 |
| 8 | 深色底要够深，别在浅色壁纸上"发灰" | 图标常被放在浅色桌面 |

---

## 三、设计语言（与应用内保持一致）

应用整体是「暗夜金脉」：极夜蓝黑打底，金色 = 已点亮。

| 元素 | 取值 | 说明 |
|---|---|---|
| 底色渐变 | `#141F33` → `#0A1020` | 柔和对角渐变，四角略深 |
| 已点亮金 | `#F5C542` | 与地图上的点亮色一致 |
| 金色光晕 | `#FFD97D` | 半透明、向外扩散 |
| 未点亮暗点 | `#4A5E82` | 低饱和蓝灰，不能比金点抢眼 |
| 气质关键词 | 克制、精密、暗夜、坐标感 | **不要** 3D 立体、塑料高光、金属反光、复杂插画 |

---

## 四、构图（当前定稿，作为基准）

- 5×5 圆点阵，整体居中；点间距约为画布的 15.5%，点直径约 1.6%
- 正中间那颗是"点亮"的：直径约 6.4%（约为暗点的 4 倍），纯金色实心
- 金点外一圈**极细光环**（半径约 5.2%，金色 50% 透明度），再外围是一层柔和金色光晕（半径约画布 40%）
- 四周留白均匀，视觉重心正好在正中

**允许的变化方向**（想要不同版本时）：

- **B 足迹路线**：点阵之上叠一条柔和的金色路径，斜穿画面串起 3 颗点（更像"旅行轨迹"）
- **C 光点涟漪**：不画点阵，只留一颗金点 + 两圈同心光环，外圈散点向外淡出（更像"信号/定位"）

## 六、拿到图之后要做的事（我来处理）

AI 出的是"一张成品图"，鸿蒙需要的是**分层图标**，所以中间要加工：

1. 抠出主体（点阵 + 金点），生成 **前景层**（透明底）
2. 底色渐变单独生成 **背景层**（满幅，不留透明边）
3. 按系统要求导出：`background.png` / `foreground.png`（1024×1024 RGBA，放 `AppScope/resources/base/media/`）
4. 导出启动图标 `startIcon.png`（144×144）与商店用图（216 / 512 / 1024）
5. 做**缩小测试**：72px、48px 各看一眼，糊了就回炉

> 注意：应用图标真正生效的是 **`AppScope/`** 下的那份资源，不是 `entry/` 模块里的——
> 这一点已经踩过坑，改错位置会导致桌面图标不变。

## 七、验收清单

- [ ] 没有文字、地图轮廓、国界线
- [ ] 72×72 缩略后主体依然清晰
- [ ] 深色底在浅色壁纸上不发灰、不发绿
- [ ] 金点与暗点对比足够（对比度目视明显）
- [ ] 边缘干净，无白边/锯齿/脏边
- [ ] 圆形遮罩裁切后主体不被切到
- [ ] 提供 1024×1024 源图（PNG，无压缩噪点）

## 八、当前定稿参数（改版时可参考）

生成脚本：`D:\China\_tools\make_icon.py`（改参数即可重出，含 A/B/C 三套方案）

|---|---|
| 画布 | 4096×4096 超采样 → 1024 输出 |
